MD Viewer 1.0
=============

Редактор Markdown с живым предпросмотром для Windows.

Нужно: Windows 10 или 11, 64-битная.
Устанавливать ничего не надо: программа запускается прямо из папки.


УСТАНОВКА
---------

1. Разблокируйте архив.
   Windows помечает скачанные файлы и потом предупреждает о них при запуске.
   Правый щелчок по zip-архиву -> «Свойства».
   Внизу на вкладке «Общие» поставьте галочку «Разблокировать» -> «ОК».
   (Если такой галочки нет — ничего делать не нужно.)

2. Распакуйте архив.
   Правый щелчок по архиву -> «Извлечь всё».
   Выберите папку, где программа будет жить постоянно,
   например «Документы\MDViewer». Не запускайте программу прямо
   из открытого архива — так она работать не будет.

3. Запустите программу.
   Откройте папку MDViewer и дважды щёлкните MDViewer.exe.
   Остальные файлы в папке (_internal) не трогайте и не удаляйте:
   без них программа не запустится.

4. Если появилось синее окно «Система Windows защитила ваш компьютер»:
   нажмите «Подробнее» -> «Выполнить в любом случае».
   Это предупреждение появляется у программ без платной цифровой подписи.
   Оно появится один раз.

5. Ярлык на рабочем столе (по желанию).
   Правый щелчок по MDViewer.exe -> «Показать дополнительные параметры»
   (в Windows 10 этого пункта нет, сразу следующий) ->
   «Отправить» -> «Рабочий стол (создать ярлык)».


ОТКРЫТИЕ ФАЙЛОВ
---------------

После первого запуска файлы .md открываются в MD Viewer двойным щелчком.
Если Windows спросит «Каким приложением открыть?» — выберите MD Viewer
и отметьте «Всегда использовать это приложение».

Файлы .html можно посмотреть так: правый щелчок -> «Открыть с помощью» ->
MD Viewer. Они открываются только для чтения.

Если вы перенесли папку программы в другое место — запустите MDViewer.exe
из нового места один раз, и двойной щелчок по .md снова заработает.


ЕСЛИ ПРОГРАММА НЕ ЗАПУСКАЕТСЯ
-----------------------------

* Сообщение «Для работы MD Viewer нужен компонент Microsoft Edge WebView2».
  Нажмите «Да» — скачается установщик с сайта Microsoft.
  Запустите его, дождитесь окончания и снова откройте MD Viewer.
  Обычно WebView2 уже есть в Windows; его может не быть на только что
  установленной Windows 10.

* Антивирус удалил или заблокировал MDViewer.exe.
  Это ложное срабатывание: программа не подписана, и некоторые антивирусы
  относятся к таким программам с подозрением. Добавьте папку программы
  в исключения антивируса или восстановите файл из карантина.

* Что-то пошло не так.
  Журнал ошибок лежит здесь: нажмите Win+R, введите
      %APPDATA%\MDViewer
  и нажмите Enter. Файл log.txt — его можно приложить к сообщению об ошибке.


ОБНОВЛЕНИЕ
----------

1. Закройте MD Viewer.
2. Удалите старую папку программы.
3. Распакуйте новую версию на то же место (пункты 1–3 установки).

Настройки, личный словарь и открытые вкладки хранятся отдельно
и при обновлении не пропадают.


ГДЕ ХРАНЯТСЯ ДАННЫЕ
-------------------

%APPDATA%\MDViewer
  config.json           — настройки
  session.json          — открытые вкладки и несохранённый текст
  user-dictionary.txt   — слова, добавленные в словарь проверки орфографии
  log.txt               — журнал ошибок

Ваши документы программа хранит там, куда вы их сохранили.
Несохранённый текст не пропадает: при следующем запуске он откроется снова.


УДАЛЕНИЕ
--------

1. Закройте MD Viewer.
2. Удалите папку программы.
3. Если не нужны настройки — удалите папку %APPDATA%\MDViewer.

Связь с файлами .md при этом останется. Чтобы .md открывались другой
программой: правый щелчок по файлу .md -> «Открыть с помощью» ->
«Выбрать другое приложение» -> отметить «Всегда использовать это приложение».
