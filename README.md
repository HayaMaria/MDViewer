# MD Viewer

Редактор Markdown для Windows с живым предпросмотром. Слева текст, справа результат: схемы, графики и таблицы рисуются прямо во время набора. Готовый документ сохраняется как `.md` или экспортируется в HTML-страницу, которая открывается в любом браузере без интернета.

## Возможности

### Что можно делать в документе

- **Обычный Markdown**: жирный, курсив, зачёркнутый и подчёркнутый текст, инлайн-код, заголовки, списки и задачи, цитаты, ссылки, разделители.
- **Таблицы** с выравниванием столбцов и заданной шириной.
- **Изображения** с компьютера или из интернета, с нужным размером.
- **Блоки кода** с подсветкой: Python, JavaScript, HTML, CSS, SQL, JSON, Bash и другие.
- **Схемы**: блок-схемы, диаграммы последовательностей, классов и состояний, временные линии.
- **UML-диаграммы**: варианты использования, деятельности, компоненты, пакеты.
- **Графики по таблице**: столбчатые, линейные, круговые, точечные и лепестковые.
- **Выравнивание** текста, таблиц и схем по центру или по правому краю.

**Синтаксис помнить не обязательно.** Форматирование ставится кнопками на панели и горячими клавишами, а таблицы, изображения, схемы и графики вставляются через диалоги: выбрали тип, заполнили данные, указали размер.

Подробнее о синтаксисе — в самой программе: меню «Справка» → «MD синтаксис» и «Горячие клавиши».

### Остальное

- **Живой предпросмотр** рядом с текстом.
- **Проверка орфографии** на русском и английском, с личным словарём.
- **Экспорт в HTML**: страница выглядит как предпросмотр, схемы уже нарисованы, графики остаются интерактивными. Картинки можно встроить в файл.
- **Просмотр HTML-файлов** только для чтения.
- **Светлая и тёмная тема.**
- **Работает без интернета.**

## Установка

Нужна Windows 10 или 11, 64-битная.

1. Скачайте `MDViewer-<версия>-setup.exe` со страницы [Releases](https://github.com/HayaMaria/MDViewer/releases).
2. Запустите установщик. Права администратора не нужны: программа ставится только для текущего пользователя.
3. Если Windows покажет синее окно «Система Windows защитила ваш компьютер», нажмите «Подробнее» → «Выполнить в любом случае». Это предупреждение появляется у программ без платной цифровой подписи.

Если на компьютере нет компонента Microsoft Edge WebView2, установщик скачает и поставит его сам (нужен интернет). Обычно WebView2 в Windows уже есть.

### Обновление и удаление

Новая версия ставится поверх старой, настройки сохраняются. Удаляется программа обычным способом: «Параметры» → «Приложения».

### Где хранятся данные

`%APPDATA%\MDViewer`:

| Файл | Что в нём |
|------|-----------|
| `config.json` | настройки |
| `session.json` | открытые вкладки и несохранённый текст |
| `user-dictionary.txt` | слова, добавленные в словарь |
| `log.txt` | журнал ошибок |

При удалении программы эта папка остаётся. Если настройки больше не нужны, удалите её вручную.

## Разработка

Программа написана на Python ([pywebview](https://pywebview.flowrl.com/) + WebView2). Интерфейс сделан на HTML/JS, редактор построен на [CodeMirror 6](https://codemirror.net/).

### Что нужно

- Python 3.11, **64-битный**
- Node.js (только если меняется код в `cm-builder/src`)
- [Inno Setup 6](https://jrsoftware.org/isinfo.php) (только для сборки установщика)

### Запуск из исходников

```bat
py -3.11 -m venv venv
venv\Scripts\python -m pip install -r requirements-dev.txt
venv\Scripts\python app.py
```

Версии в `requirements.txt` закреплены специально: код опирается на внутренние детали pywebview и pythonnet. Обновлять их только вручную, с проверкой.

### Тесты

```bat
venv\Scripts\python -m pytest
```

### Редактор (cm-builder)

CodeMirror, проверка орфографии и графики для экспорта собираются Vite в `assets/build/`. Готовые бандлы лежат в репозитории, так что пересобирать их нужно только после правок в `cm-builder/src`:

```bat
cd cm-builder
npm install
npm run build
```

### Сборка установщика

```bat
build.bat
```

Скрипт берёт номер версии из `mdviewer/__init__.py`, собирает программу PyInstaller'ом в `dist\MDViewer`, скачивает официальный установщик WebView2 (и проверяет подпись Microsoft), а потом собирает `dist\MDViewer-<версия>-setup.exe`.

`build.bat` требует собственный загрузчик PyInstaller, собранный на этом компьютере: со стандартным антивирусы чаще дают ложные срабатывания. Один раз (и после каждой переустановки PyInstaller) запустите `tools\build_bootloader.bat`. Для него нужны Microsoft C++ Build Tools с нагрузкой «Разработка классических приложений на C++».

### Структура

| Путь | Что там |
|------|---------|
| `app.py` | точка входа: окно, сочетания клавиш, запуск |
| `mdviewer/` | Python-часть: документы, сессия, настройки, экспорт, изображения |
| `mdviewer/win/` | всё, что зависит от Windows: заставка, буфер обмена, единственный экземпляр, проверка WebView2 |
| `assets/` | интерфейс: HTML, CSS, JS, тексты справки, библиотеки (Mermaid, nomnoml, Chart.js) |
| `cm-builder/` | исходники редактора на CodeMirror 6 |
| `installer/` | скрипт установщика Inno Setup |
| `tools/` | загрузчик PyInstaller и служебные скрипты |
| `tests/` | тесты pytest |
