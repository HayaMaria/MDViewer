## Ошибки

### Важно — до раздачи

- [x] **Нет WebView2 → непонятная ошибка и зависшее окно.** На чистой Windows 10 WebView2 не было. pywebview молча переключился на движок Internet Explorer, тот не понял `editor.bundle.js`: «Ошибка сценария, строка 1, символ 48», экран загрузки висит.
  **Исправлено:** `mdviewer/win/webview2.py` проверяет WebView2 до открытия окна. Если его нет — окно Windows «Для работы MD Viewer нужен компонент Microsoft Edge WebView2…», по «Да» браузер скачивает установщик с сайта Microsoft, программа закрывается.
  Осталось: описать в «Прочитай меня.txt»; проверить на снимке виртуальной машины без WebView2.

- [x] **Открытие файла из Проводника заменяет прошлую сессию.** В прошлой сессии были открыты `проверочка` и несохранённый «Новый документ». После открытия файла через «Открыть с помощью» открылся только этот файл, несохранённый текст прошлой сессии пропадал при первой записи сессии.
  **Исправлено:** при запуске с файлом сначала восстанавливается прошлая сессия, потом файл открывается отдельной вкладкой (`documents.start_with_file`).

- [x] **Каждый запуск — отдельная копия программы.** Повторное открытие уже открытого файла из Проводника открыло второе окно с тем же файлом.
  **Исправлено:** `mdviewer/win/single_instance.py`. Первая копия слушает именованный канал. Повторный запуск передаёт ей файл и закрывается: файл открывается вкладкой в уже открытом окне (или переключает на уже открытую вкладку), окно выходит на передний план. Повторный запуск без файла (ярлык, `MDViewer.exe`) открывает новое окно.

- [ ] **Восстановление сессии из нескольких окон: первое открытие висело ~3 минуты и не загрузилось.** Было 2 окна (2 и 3 вкладки), закрыты, программа запущена снова — окно грузилось 3 минуты. После закрытия и повторного запуска открылось одно окно со всеми пятью вкладками.
  То, что окно одно, — так задумано (`session.merge_windows`: «при запуске открывается одно окно»), ожидание в чек-листе исправлено. Зависание на основном компьютере не воспроизводится. Вероятная причина — несколько копий программы одновременно (окна открывались двойным щелчком по файлам), они по очереди переписывали `session.json`. Это исправлено выше.
  Осталось: повторить 7.4 на новой сборке. Если зависнет снова — сразу забрать `%APPDATA%\MDViewer\log.txt`.

- [x] **Ctrl+I не ставит курсив, а расширяет выделение** (строка → весь список → и только потом звёздочки). Кнопка на панели работает.
  **Исправлено:** в `cm-builder/src/editor.js` наши сочетания подключены с `Prec.high`, стандартный Ctrl+I CodeMirror («выделить родительский блок») их больше не перебивает. Другие конфликты: у CodeMirror ещё Ctrl+U, но его и раньше перехватывала программа.

### Решено

- [x] **Ctrl+N и Ctrl+T делали одно и то же.** Теперь Ctrl+T — новая вкладка, Ctrl+N — новое окно. Меню «Файл» и «Горячие клавиши» обновлены.
- [x] **Пустой несохранённый документ сохранялся в сессии.** Теперь «Новый документ», в котором ничего не набрано, при следующем запуске не восстанавливается. Документ с текстом — восстанавливается.

### Обсудить

- [ ] **F12 и Ctrl+Shift+I открывают панель разработчика.** Сломать через неё ничего нельзя, но обычному пользователю там делать нечего. Можно перехватить эти клавиши так же, как Ctrl+U и Ctrl+плюс.
- [ ] **Одну-единственную вкладку неудобно перетаскивать.** Если случайно вытащить вкладку в новое окно и она там одна, вернуть её обратно очень сложно. Доработать перетаскивание.
- [ ] **MD Viewer глубоко в «Открыть с помощью».** Для файла без связи с программой нужно «Выбрать другое приложение» → «Ещё приложения» → прокрутить вниз. Перепроверить на настоящем `.md` (см. ниже) — для него программа должна быть в коротком списке.

### Не ошибки

- **Файлы `проверочка.md.txt`.** Windows по умолчанию скрывает расширения: «Новый текстовый документ», переименованный в `проверочка.md`, на самом деле называется `проверочка.md.txt`. Поэтому двойной клик открыл Блокнот, а в программе было видно `.md.txt`. Что программа открывает `.txt` как текст — нормально.
- **В `log.txt` старое время изменения.** В лог пишутся только предупреждения и ошибки, а не каждый запуск. Строка `MSHTML is deprecated…` осталась от запуска до установки WebView2 — это и есть подтверждение первой ошибки.
- **Окно SmartScreen** — ожидаемо для программы без подписи. Пришлось разблокировать через «Свойства». Описать в «Прочитай меня.txt».
