-- Схемы (графы Mermaid) --
```mermaid
flowchart TD
  A[Начало] --> B[Конец]
```

  Направление графа:
    • flowchart TD  — сверху вниз
    • flowchart BT  — снизу вверх
    • flowchart LR  — слева направо
    • flowchart RL  — справа налево

  Пример:
    ```mermaid
    flowchart TD
      A[Начало] --> B{Условие}
      B -- Да --> C[Действие]
      B -- Нет --> D[Отмена]
    ```

-- UML-диаграммы (Mermaid) --
```mermaid
sequenceDiagram
  A->>B: Сообщение
```

  • последовательности — sequenceDiagram
    ```mermaid
    sequenceDiagram
      participant A as User
      participant B as Server
      A->>B: Request
      B-->>A: Response
    ```

  • классов — classDiagram
    ```mermaid
    classDiagram
      class Animal {
        +String name
        +eat()
      }
      class Dog {
        +bark()
      }
      Dog <|-- Animal
    ```

  • состояний — stateDiagram
    ```mermaid
    stateDiagram
      [*] --> Idle
      Idle --> Running
      Running --> [*]
    ```

  • временные линии — timeline
    ```mermaid
    timeline
      title History
      2020: Launch
      2021: Growth
      2022: Leader
    ```

-- UML-диаграммы (Nomnoml) --
```nomnoml
[Актор] -> (Действие)
```

  • варианты использования (Use Case)
    ```nomnoml
    [User]
    [Admin]
    [User] -> [Login]
    [User] -> [View]
    [Admin] -> [Manage]
    ```

  • деятельности (Activity)
    ```nomnoml
    [start] -> [Step 1]
    [Step 1] -> [Step 2]
    [Step 2] -> [end]
    ```

  • компонентов (Component)
    ```nomnoml
    [Client] <-> [API]
    [API] <-> [Service A]
    [API] <-> [Service B]
    [Service A] <-> [(DB)]
    [Service B] <-> [(DB)]
    ```

  • пакетов (Package)
    ```nomnoml
    [Client Layer]
    [Business Logic]
    [Data Layer]
    [Client Layer] <-> [Business Logic]
    [Business Logic] <-> [Data Layer]
    ```

-- Графики Chart.js --
```chart
настройки и таблица
```

  Строит графики на основе таблицы с данными.
  Первая строка — type: тип_графика.
  Затем идёт таблица: первый столбец — подписи,
  остальные — числовые значения.

  Типы графиков:
    • bar       — столбчатый
    • line      — линейный (тренд)
    • pie       — круговой (доли)
    • doughnut  — кольцевой
    • radar     — лепестковый
    • polarArea — полярный

  Пример — столбчатый график:
    ```chart
    type: bar
    | Месяц | Продажи |
    |-------|---------|
    | Янв   | 30      |
    | Фев   | 50      |
    | Мар   | 70      |
    ```
  Таблица рисуется чёрточками и палками:
  | заголовок | заголовок | — строка шапки
  |-----------|-----------| — разделитель
  | значение  | число     | — строка данных
