-- Редактирование --
Ctrl+Z — Отмена
Ctrl+Y / Ctrl+Shift+Z — Повтор
Ctrl+X — Вырезать
Ctrl+C — Копировать
Ctrl+V — Вставить
Tab / Ctrl+] — Увеличить отступ
Shift+Tab / Ctrl+[ — Уменьшить отступ
Alt+↑ / Alt+↓ — Переместить строку выше / ниже
Shift+Alt+↑ / Shift+Alt+↓ — Скопировать строку выше / ниже
Ctrl+Shift+K — Удалить строку
Ctrl+Enter — Новая строка под текущей (курсор может стоять где угодно)
Win+H — Голосовой ввод

-- Файловые операции --
Ctrl+T — Новая вкладка
Ctrl+N — Новое окно
Ctrl+O — Открыть файл
Ctrl+S — Сохранить
Ctrl+Shift+S — Сохранить как
Ctrl+W — Закрыть вкладку
Ctrl+Q — Выход
Ctrl+Tab / Ctrl+Shift+Tab — Следующая / предыдущая вкладка

-- Форматирование --
Ctrl+B — Жирный
Ctrl+I — Курсив
Ctrl+U — Подчёркнутый
Ctrl+Shift+X — Зачёркнутый
Ctrl+` — Инлайн-код (` — обратная кавычка, клавиша Ё)
Ctrl+Shift+Enter — Пустая строка (видна в HTML)

-- Навигация --
Home / End — В начало / конец строки
Ctrl+Home — В начало документа
Ctrl+End — В конец документа
Ctrl+стрелки — Переход по словам

-- Выделение --
Shift+стрелки — Выделение текста
Ctrl+A — Выделить всё
Alt+L — Выделить строку
Ctrl+D — Следующее совпадение
Ctrl+Shift+L — Все совпадения сразу
Ctrl+Alt+↑ / Ctrl+Alt+↓ — Ещё один курсор выше / ниже
Esc — Снова один курсор

-- Поиск --
Ctrl+F — Открыть / закрыть поиск
Enter — Следующее совпадение
Shift+Enter — Предыдущее совпадение
Esc — Закрыть поиск

-- Вид --
Ctrl+плюс — Шрифт редактора крупнее
Ctrl+минус — Шрифт редактора мельче
Ctrl+0 — Обычный размер шрифта (15px)
Esc — Закрыть меню или окно
