-- Редактирование --
Ctrl+Z / Cmd+Z — Отмена
Ctrl+Y / Cmd+Y — Повтор
Ctrl+X / Cmd+X — Вырезать
Ctrl+C / Cmd+C — Копировать
Ctrl+V / Cmd+V — Вставить
Tab — Увеличить отступ
Shift+Tab — Уменьшить отступ

-- Файловые операции --
Ctrl+N / Cmd+N — Новый документ
Ctrl+T / Cmd+T — Новая вкладка
Ctrl+O / Cmd+O — Открыть файл
Ctrl+S / Cmd+S — Сохранить
Ctrl+Shift+S / Cmd+Shift+S — Сохранить как
Ctrl+W / Cmd+W — Закрыть вкладку
Ctrl+Q / Cmd+Q — Выход
Ctrl+Tab / Ctrl+Shift+Tab — Следующая / предыдущая вкладка

-- Форматирование --
Ctrl+B / Cmd+B — Жирный
Ctrl+I / Cmd+I — Курсив
Ctrl+U / Cmd+U — Подчёркнутый
Ctrl+Shift+X / Cmd+Shift+X — Зачёркнутый
Ctrl+` / Cmd+` — Инлайн-код
Ctrl+Shift+Enter / Cmd+Shift+Enter — Пустая строка (видна в HTML)

-- Навигация --
Home / End — В начало / конец строки
Ctrl+Home / Cmd+Home — В начало документа
Ctrl+End / Cmd+End — В конец документа
Ctrl+стрелки / Cmd+стрелки — Переход по словам

-- Выделение --
Shift+Стрелки — Выделение текста
Ctrl+A / Cmd+A — Выделить всё
Ctrl+D / Cmd+D — Следующее совпадение
Ctrl+F / Cmd+F — Поиск
